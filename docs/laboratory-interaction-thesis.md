# Watch, intervene, inspect

The laboratory is a causal explanation before it is a dashboard. Keep the existing architecture films, component microscopes and six result figures. Add a guided layer whose visual objects survive each intervention.

## Storyboards

- Inference: an unchanged cohort enters static paired batches; release each worker independently; reuse an already-computed prefix; reduce the declared cost per token; compose these effects. Scheduling changes waiting, reuse changes repeated work, kernel efficiency changes cost per unit of work. None changes the answer. Distinguish paged allocation from prefix reuse: paging alone is not credited with fewer FLOPs.
- Post-training: Base → SFT → correctness RL → the same RL checkpoint with more inference-time thought → an efficiency-aware policy. Keep a stable 96-task outcome map, expose gained and lost task identities, and move the current result through a cost–accuracy space. More thought is not another weight update. The reasoning tree is a conceptual illustration, not captured model trajectories.

## Interaction contract

- Watch: a short, finite five-chapter sequence. Visible chapter rail, pause, replay, manual previous/next. Stop at the conclusion rather than looping forever.
- Intervene: workload and thought-budget controls recompute the deterministic cohort. Undo the current intervention to compare with the preceding state, without losing position.
- Inspect: focus/hover a mechanism or task to temporarily hold narration and expose a linked explanation. Click/tap pins it; Escape or a visible close action releases it. No information is hover-only. Details occupy a reserved inspector, not a cursor-following tooltip covering the diagram.
- Explore: retain the original six result figures as an adjacent mode. Evidence and downloadable task-level records remain available.
- Motion: animate changes in position, extent and emphasis, not decorative randomness. Pause offscreen and in hidden tabs; reduced motion disables automatic progression and animation but retains all manual controls.

## Sources and deliberate boundaries

The public [Chartosaur playbook](https://www.chartosaur.com/playbook) demonstrates a single-variable baseline slider and de-jargon interactions. Adopt focused interventions and guided attention; do not adopt truncated quantitative axes or copy its visual identity. [Distill's attention explanation](https://distill.pub/2016/augmented-rnns/) motivates direct correspondence between an inspected object and an explanation; keep our own dark observatory, amber/rose accents and vector vocabulary.

The original simulator is deterministic illustrative data, not a physical Qwen run. Keep a concise, visible synthetic-scenario label; move repeated caveats into the evidence inspector. No numbers are borrowed or perturbed from other research, no hardware identity is invented, and no toy trajectory is described as a real model trace. Add independent runtime switches while retaining the original default simulation outputs. Export the exact mechanism settings with each story record.

Mechanism checks also used the primary [vLLM PagedAttention documentation](https://docs.vllm.ai/en/latest/design/paged_attention/) and [TRL GRPO documentation](https://huggingface.co/docs/trl/grpo_trainer). These ground the terminology and allocation/optimization distinctions, not the numeric coefficients. External references are adopted only where they improve this project's explanation; they do not replace the established design standard.

## Verification

Test every intervention for unchanged task identity, output tokens and correctness on the inference track; first-use cache readiness; no overlapping worker execution; exact busy-work accounting; queue-inclusive p95; and consistent aggregation. Test training transitions against the same simulator and explicitly expose negative flips. Browser-check pause, replay, undo, hover/focus, pin, Escape, touch-sized controls, narrow screens, reduced motion and both exploration modes.

Verified: 27 compute/motion/story tests, TypeScript, targeted ESLint, production build and three server-rendering checks. Live browser checks covered automatic progression, hover hold across multiple chapter intervals, pin/release, Escape, reversible interventions, the unrelated-prefix zero-benefit case, 1×/8× thought, keyboard access to task 96, evidence download identity, all six exploration tabs, 390px layout and reduced motion. Temporary viewport/media overrides were reset; no browser console errors were reported. One existing legacy source-shape test still expects `const ROLES` in the separately edited profile component and remains outside this change.

## Spatial and numerical argument

The request view places waiting seconds and GPU busy-work in separate columns, with distinct scales and explicit units. Four cumulative runtime rows preserve request identity: baseline, independent scheduling, prefix reuse, faster rates. During scheduling, work is quiet; during compute interventions, waiting is quiet. The exact delta bracket is connected to the card. The final saved-work segments carry their own numerical contribution labels, not just a matched color.

`runtime-gains-study.ts` checks intervention order and matched cognition, retains request 7, checks unchanged scheduling work and prefix decode, and rejects cache-outcome changes in the rate comparison. Cost contributions are differences between consecutive conditions, not independent percentages added together. Waiting is never included in compute savings. All requests, including unsuccessful ones, contribute work to the numerator; the correct-outcome denominator stays fixed.
